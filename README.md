# CarSpot

An Android marketplace for buying and selling cars, with an AI-powered assistant to help you find the right one.

## What it does

- Browse car listings with filters
- Post your own car for sale with photos
- Chat with **CarBot**, an AI assistant (OpenAI) that helps you search
- Like and save your favorite listings
- Manage your profile and your ads
- Real-time data and push notifications

## Tech Stack

| Layer | Tech |
|-------|------|
| Language | Kotlin |
| Architecture | LiveData |
| Backend | Firebase (Firestore, Auth, Storage, FCM) |
| AI | OpenAI API via Retrofit |
| Images | Glide |
| UI | Material Design 3, Jetpack Navigation |

## Getting Started

1. Clone the repo
2. Add your `google-services.json` in `/app`
3. Set your OpenAI API key in the network config
4. Build & run with Android Studio (minSdk 24)
